# سامانه مشترک ثبت تولید نوین

این نسخه برای استفاده هم‌زمان روی چند کامپیوتر کارخانه طراحی شده است. تمام کاربران به یک سرور و دیتابیس مرکزی SQLite متصل می‌شوند؛ بنابراین ثبت هر کامپیوتر برای سایر کاربران نیز قابل مشاهده است.

## روش ساده نصب در شبکه داخلی کارخانه

### ۱. انتخاب کامپیوتر سرور

یک کامپیوتر ویندوزی را انتخاب کنید که هنگام کار کارخانه روشن و به شبکه داخلی متصل باشد. پوشه `novin-production-server` را کامل روی همان کامپیوتر کپی کنید.

### ۲. نصب Python

اگر Python 3 روی کامپیوتر نصب نیست، آن را از `python.org` نصب کنید و هنگام نصب گزینه **Add Python to PATH** را فعال نمایید. برنامه به هیچ بسته اضافی نیاز ندارد.

### ۳. اجرای برنامه

روی فایل زیر دوبار کلیک کنید:

```text
start_server.bat
```

مرورگر سرور با آدرس زیر باز می‌شود:

```text
http://localhost:8080
```

ورود اولیه مدیر:

```text
نام کاربری: admin
رمز عبور: admin123
```

پس از ورود، از بخش «کاربران» حساب‌های کارمندان را ایجاد و رمز مدیر را تغییر دهید.

### ۴. ورود از کامپیوترهای دیگر

روی سرور فایل `show_ip.bat` را اجرا کنید و IPv4 را پیدا کنید؛ مثلاً:

```text
192.168.1.20
```

سپس در مرورگر سایر کامپیوترهای همان شبکه وارد کنید:

```text
http://192.168.1.20:8080
```

اگر پنجره Windows Firewall ظاهر شد، دسترسی Python را برای **Private networks** مجاز کنید.

## محل ذخیره اطلاعات

اطلاعات در فایل زیر روی سرور نگهداری می‌شوند:

```text
data/production.db
```

این فایل را حذف نکنید. برای پشتیبان‌گیری، علاوه بر دکمه «دانلود پشتیبان» داخل برنامه، می‌توانید هنگام خاموش‌بودن سرور از کل پوشه `data` کپی بگیرید.

## انتقال اطلاعات نسخه HTML قبلی

۱. در نسخه قدیمی تک‌فایلی با مدیر وارد شوید.
۲. از بخش کاربران، «دانلود پشتیبان» را بزنید.
۳. در نسخه شبکه‌ای به بخش «پشتیبان» بروید.
۴. فایل JSON قبلی را انتخاب و بازیابی کنید.

فیلدهای کالا و ثبت تولید نسخه قبلی با این نسخه سازگار شده‌اند. کاربران قدیمی به‌دلایل امنیتی خودکار منتقل نمی‌شوند و باید دوباره توسط مدیر ایجاد شوند.

## نقش کاربران

- **مدیر:** ثبت تولید، گزارش‌ها، تعریف کالا، مدیریت کاربران، حذف ردیف و پشتیبان‌گیری.
- **کارمند:** ثبت تولید و مشاهده گزارش‌ها؛ امکان تغییر کاربران یا کالاها را ندارد.

## نکات مهم

- پنجره مشکی سرور باید باز بماند.
- کامپیوتر سرور نباید هنگام کار کاربران خاموش یا Sleep شود.
- همه کامپیوترها باید به شبکه داخلی مشترک متصل باشند.
- برای دسترسی از بیرون کارخانه، بهتر است برنامه روی سرور ابری با HTTPS و تنظیمات امنیتی تکمیلی نصب شود.
- این نسخه برای شبکه داخلی قابل اعتماد طراحی شده است؛ پورت 8080 را مستقیماً روی اینترنت عمومی باز نکنید.
